📍 定位诊断

解决步骤（按顺序检查）：
1️⃣ 手机系统定位服务打开：设置 → 位置信息 → 开
2️⃣ 浏览器权限：点地址栏左侧 🔒 图标 → 权限 → 位置信息 → 允许
3️⃣ Chrome：菜单 → 设置 → 网站设置 → 位置信息 → 确认本网站未被阻止
4️⃣ 换 Chrome / Edge 打开本页（部分浏览器不支持 file:// 定位）
5️⃣ 到室外开阔地，首次定位需等 30 秒–2 分钟
6️⃣ iPhone：设置 → 隐私与安全性 → 定位服务 → Safari/Chrome → 使用App期间
